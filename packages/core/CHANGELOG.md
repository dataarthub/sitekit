## 0.1.0 — npm publication pending

### Added

- Build static Astro sites from one inline, file or HTTP publication, with revision and SHA-256 image checks before rendering.
- Use provider-independent content, media, section, access, search and analytics contracts in independent sites or managed publishing flows.

This initial candidate requires Node.js 24+ and Astro 7.3.3 through the supported 7.x range. React-based editing additionally requires the declared optional React/Appkit peers and documented styles. Publication is a separate verified operation.
