# Changelog

## 0.1.0 — npm publication pending

### Added

- Build static Astro sites from one inline, file or HTTP publication, with revision and SHA-256 image checks before rendering.
- Use provider-independent content, media, section, access, search and analytics contracts in independent sites or managed publishing flows.
- Add optional basic Markdown management, typed errors, configuration JSON Schema and package-owned consumer guidance.

### Compatibility

This initial candidate requires Node.js 24+ and Astro 7.3.3 through the supported 7.x range. React-based editing additionally requires the declared optional React/Appkit peers and documented styles. Publication is a separate verified operation.

### Changed

- Use the SiteKit documentation routes under `https://tech-docs.alneas.com/sitekit/` in package metadata and consumer guidance.

- Align npm author, descriptive summary and discovery keywords with the ALNEAS package metadata standard.

- Use public Appkit 0.2.0 for the optional UI/editing integrations. Node.js 24 or later is required; React peers remain compatible with the declared React 19 range.

- Package history is linked from npm/GitHub READMEs and retained per package during builds; reviewed release notes are bound to the exact archive bundle.

- Clarify the unpublished candidate status in packaged README/AI guidance and require per-target delivered-version confirmation before portal ingestion.
